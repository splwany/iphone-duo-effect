# 工程化重构验证

日期：2026-09-14。视觉基线：全参数精调 23；原版保存在 Git 提交 `4fb5729`。

## 保持不变的部分

- 顶点、片元着色器和 WebGL 绘制参数，包括 24 次采样、sRGB 处理、无额外变暗、DPR 上限 1.5。
- 重力校准算法、角度方向、两层时间平滑、手动和体感切换规则。
- 11 项参数的默认值、百分比映射、localStorage 键名与旧值迁移。
- DOM 层级、文案、CSS 规则及覆盖顺序、示例和主屏幕 metadata。
- 沉浸时将 stage 移至 body，退出后恢复原位置；保留 iPhone standalone 高度算法。
- 图片仅本机处理，35 MB 限制、2600 px 降采样与 CSS 回退。

## 工程变更

- Vite 开发与生产构建、React 页面组件、严格 TypeScript 类型检查。
- 参数配置、渲染器、传感器跟踪和体验控制器分离。
- 使用 React 生命周期建立和清理事件、动画、定时器、观察器与 GPU 资源。
- 锁定依赖解析结果，增加格式检查、Node 版本约定、Git 忽略规则。
- Python HTTPS 服务改为仅提供 dist/。删除重复源码快照；Git 保留原版。

## 自动验证

- `npm run build`：类型检查及生产打包通过。
- `npm test`：8 项测试通过，覆盖稳定/不稳定校准、左右保持、无效加速度、参数中点、旧值迁移和存储不可用。
- `npm run format:check`：通过。
- Chrome 无头浏览器，1280×1000 和 393×852，DPR 1：原版与开发版初始整页 PNG 字节一致。
- 两种尺寸下手动滑块 0、25、42、50、58、75、100，以及模糊强度 0、50、100：原版与开发版画布 PNG 字节一致。
- 验证 StrictMode 下仅有一个画布、设置刷新保留、恢复全部 50%、导入示例、沉浸进出后节点位置、诊断文字和无页面异常。
- 同一浏览器交互脚本也用于生产构建预览。

`npm run test:browser` 需要已启动本地服务与已安装的 Google Chrome。
通过 `APP_URL` 指定待测服务；可选 `BASELINE_URL` 启用原版像素对比。
