# 参数可感知性优化

## 检查结论

使用默认示例、180×390 CSS 像素预览、DPR 1，对 10 项视觉参数分别在 0°、15°、45°、75° 比较 0/50/100%；跟手平滑单独检查动态响应。

- 边缘柔化原范围 0.5–1.5，主要影响 mipmap 采样轮廓，容易被 0.75 CSS 像素的抗锯齿下限和整体模糊掩盖。
- 散射集中度、细节融合范围偏窄，端点在示例上的区别较弱。细节融合还受基础缩小 LOD 下限限制，旧范围在 15° 下完全没有区别。
- 横向拉伸的旧低端 0.8 仍保留了较强拉伸。
- 跟手平滑原为 10–60 ms，静态画面没有区别，运动中差距也较短。
- 模糊强度、远端内缩、模糊加速已有明确作用，保留范围。横向/纵向散射与大角度扩散依赖倾角，75° 时差异明显，保留范围并明确提示适用条件。
- 模糊强度为零时，散射相关参数自然不起作用；居中时保持清晰，不能用静态居中画面判断所有参数是否有效。

## 新范围

| 控件 | 0% | 50%（原默认） | 100% |
|---|---:|---:|---:|
| 模糊强度 | 0 | 0.1 | 0.2 |
| 横向拉伸 | 0 | 0.9 | 1 |
| 远端内缩 | 0 | 0.13 | 0.26 |
| 模糊加速 | 1 | 2 | 3 |
| 散射集中度 | 0 | 2 | 24 |
| 横向散射 | 0 | 2 | 4 |
| 纵向散射 | 0 | 1 | 2 |
| 大角度扩散 | 0.25 | 0.5 | 0.75 |
| 边缘柔化 | 0 | 1 | 12 |
| 细节融合 | 0 | 0.7 | 4 |
| 跟手平滑 | 10 ms | 35 ms | 250 ms |

两段线性映射在 50% 连续。边缘柔化的新增高端增量随倾斜逐渐生效，居中不引入大范围羽化；0% 仍保留抗锯齿和内容散射带来的自然边界过渡。
细节融合的 0% 保留基础缩小过滤，避免原始高分辨率图像锯齿。跟手平滑为指数时间常数，不是固定延迟。

## 旧设置

更改范围的参数使用新存储键；读取顺序为新键 → 上版键 → 最早版键 → 默认值。
上版百分比先还原为内部参数值，再反算为新百分比，页面取最近的整数刻度，可能存在一个刻度内的误差。
边缘柔化高端另有倾角响应变化，不宣称旧非默认值完全等效。所有 50% 的默认内部值保持不变。

## 验证

`npm test` 检查单调性、连续性、正反映射和旧设置迁移。
`npm run test:parameters` 需要 8765 开发服务与 Chrome，生成 PNG 对比图和 JSON 像素统计，默认写入系统临时目录。
可设 `PARAM_BASELINE=/path/to/before.png` 对比 45° 时整列默认值画面；`PARAM_OUTPUT` 指定输出前缀。

45°、默认示例的端点 RGB 平均绝对差（0–255；仅用于同图、同环境对比，不等价于主观感知评分）：

| 参数 | 优化前 | 优化后 |
|---|---:|---:|
| 边缘柔化 | 0.381 | 3.267 |
| 散射集中度 | 0.915 | 1.763 |
| 细节融合 | 0.866 | 4.837 |
| 横向拉伸 | 4.376 | 9.118 |

白色测试图的边缘端点明显变化像素占比从 2.74% 增至 12.15%（RGB 平均差 >8）。
实际动画以相同 64 ms 步进比较快慢端点。iPhone 真机的主观感受仍需实测；大角度、多项同时最大时可能显著损失细节。
